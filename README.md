A collection of Java programs written while learning core programming concepts — arrays, OOP, number problems, pattern printing, and string manipulation. Created for practice and reference.

## Folder Structure

basic/
├── array/    - Array operations (sorting, searching, duplicates)
├── basic/    - OOP concepts (inheritance, constructors, overriding)
├── number/   - Number-based problems (factorial, fibonacci, armstrong, etc.)
├── star/     - Pattern printing programs (pyramid, diamond, triangle)
└── string/   - String manipulation (palindrome, reverse, vowels)
